# What to do:
- `npm init -y`, for generating package.json 
- Install and import "express" module.
- Create `HTTP` sever.
- Create API.
- API routs
    GET ---> app.get('path', request handler)
    POST ---> app.post('path', request handler)
    PUT ---> app.put('path', request handler)
    DELETE ---> app.delete('path', request handler)
- Preparing client requests. (with the help of *post man* or *rest client*
    - Rest Client is available as an extention in VSCode.
